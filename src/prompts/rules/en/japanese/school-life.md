# School-Life Genre Rules

## Japanese Source Terms
- 学園 / 学校 -> academy / school
- 先生 -> teacher / professor / doctor, depending on context
- 先輩 / 後輩 -> senior / junior / senpai / kouhai, depending on glossary
- 委員長 -> class representative / class president
- 生徒会 -> student council
- 部活 -> club activity / club
- 幼馴染 -> childhood friend
- 告白 -> confession / love confession, depending on context

## Style
- Keep school-life dialogue youthful, natural, and lightly witty when the source tone allows it
- Preserve awkwardness, crush tension, teasing, and small daily details
- Do not make teenagers sound like formal adults unless the source deliberately does
- Avoid over-romanizing ordinary school terms when a natural English term exists
