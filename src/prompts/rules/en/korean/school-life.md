# School-Life Genre Rules

## Korean Source Terms
- 학교 -> school
- 선생님 -> teacher / instructor, depending on context
- 선배 / 후배 -> senior / junior / upperclassman / underclassman, depending on context
- 반장 -> class president / class representative
- 학생회 -> student council
- 동아리 -> club
- 소꿉친구 -> childhood friend
- 고백 -> confession / love confession, depending on context

## Style
- Keep school-life dialogue youthful, natural, and lightly witty when the source tone allows
- Preserve hierarchy expressed through 존댓말, 반말, titles, and school seniority without making teenagers sound artificially formal
- Preserve awkwardness, crush tension, teasing, competition, and small daily details
- Prefer natural English school terminology unless the glossary deliberately retains a Korean term
