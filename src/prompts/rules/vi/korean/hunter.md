# Hunter / Regression Genre Rules

## Korean Source Terms
- 회귀 → hồi quy
- 회귀자 → người hồi quy
- 각성 → giác tỉnh / thức tỉnh
- 각성자 → giác tỉnh giả
- 헌터 → Hunter (keep original)
- 던전 → dungeon (keep original)
- 레이드 → raid (keep original)
- 길드 → guild (keep original)
- 마나 → mana (keep original)
- 스킬 → skill (keep original)
- S급 → hạng S
- A급 → hạng A
- 랭킹 → ranking (keep original)

## Style
- Keep combat, raids, and tactical decisions fast, concrete, and easy to visualize
- Render ranks, skills, status information, and system messages compactly and consistently
- Preserve the protagonist's planning and foreknowledge in regression scenes without adding explanations
- Use punchy dialogue when the source is terse, but retain hierarchy and professional distance between Hunters
