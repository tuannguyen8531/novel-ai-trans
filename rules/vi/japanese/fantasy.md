# Fantasy Genre Rules

## Japanese Source Terms
- 勇者 → dũng giả
- 魔王 → ma vương
- スキル → skill (keep original)
- レベル → level (keep original)
- ステータス → status (keep original)
- ダンジョン → dungeon (keep original)
- 冒険者 → mạo hiểm giả / phiêu lưu gia
- ギルド → guild (keep original)
- 魔法 → ma pháp
- 魔物 → ma vật / quái vật
- 聖女 → thánh nữ
- 騎士 → kỵ sĩ

## Style
- Keep magic systems, ranks, roles, races, and institutions terminologically consistent
- Preserve the setting's social register without making all fantasy dialogue archaic
- Keep skills, levels, status panels, and system messages compact when present
- Preserve the distinction between Japanese names and Western-derived in-world names established by the naming policy
