# Hunter / Regression Genre Rules

## Korean Source Terms
- 회귀 -> regression / return to the past
- 회귀자 -> regressor
- 각성 -> awakening
- 각성자 -> awakened / awakened person
- 헌터 -> Hunter
- 던전 -> dungeon
- 레이드 -> raid
- 길드 -> guild
- 마나 -> mana
- 스킬 -> skill
- 상태창 -> status window
- 랭커 -> ranker
- S급 / A급 -> S-rank / A-rank
- 랭킹 -> ranking

## Style
- Keep combat, raids, and tactical decisions fast, concrete, and easy to visualize
- Render ranks, skills, status information, and system messages compactly and consistently
- Preserve the protagonist's planning and foreknowledge in regression scenes without adding explanations
- Use punchy dialogue when the source is terse, while retaining hierarchy and professional distance between Hunters
