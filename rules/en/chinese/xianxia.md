# Xianxia / Xuanhuan Genre Rules

## Chinese Source Terms
- 修炼 -> cultivate / train / practice cultivation
- 境界 -> realm / stage
- 灵气 -> spiritual energy / qi, depending on glossary
- 丹药 -> pill / elixir
- 法宝 -> magical treasure / artifact
- 功法 -> cultivation method / technique
- 突破 -> break through / breakthrough
- 渡劫 -> undergo tribulation / pass the heavenly tribulation
- 内力 -> internal force
- 真气 -> true qi
- 元神 -> primordial spirit / nascent soul, depending on genre context
- 神识 -> divine sense / spiritual sense

## Style
- Use an elevated cultivation register when the source is solemn, while keeping ordinary narration readable
- Keep realm names, techniques, artifacts, and progression terminology exact and consistent
- Convey hierarchy through titles and address choices; do not manufacture archaic English when the source is plain
- Preserve escalation, spatial clarity, and the weight of each power change in combat and breakthrough scenes
